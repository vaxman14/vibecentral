Yours, not ours

Read-only by design.

vibecentral never deploys, charges, deletes or sends anything. It only looks. It runs on your own server, so your keys and your numbers never leave it.

Self-host

Up and running over a coffee.

Four steps from clone to a dashboard that knows everything you ship.

Clone the repo

Grab vibecentral from GitHub and drop it on any server you like.

Add read-only keys

Paste a read-only token for each service you use. Skip the ones you don't.

Deploy it

Put it on your own domain. It's yours alone, not a shared app.

Sign in with a passkey

Face ID or Touch ID, and your whole stack is on one screen.
